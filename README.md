#### 01. GridFlowX — AI-Driven Microgrid Management Platform

`PRODUCTION` · `CYBER-PHYSICAL` · `DIGITAL TWIN` · `ENERGY AUTOMATION`

> **An integrated microgrid supervisory platform bridging edge power transducers with real-time forecasting and 3D digital twin telemetry.**

- **Engineering Problem:** Microgrids combining solar arrays, battery storage banks, and utility feeds require deterministic edge safety cutoffs that must never be compromised by network latency, cloud outages, or socket disconnections.
- **Engineering Approach:** Dual-core ESP32 architecture partitions execution: Core 1 runs a deterministic 100Hz hardware safety loop independent of all network tasks, while Core 0 manages async WebSocket telemetry streaming to a Next.js 15 / Three.js spatial digital twin with multi-tier role-based access control.
- **Key Implementation:** Dual-core FreeRTOS firmware with mutex-protected telemetry queues, FastAPI async WebSocket broker, relay-override and emergency recovery REST endpoints, Firebase multi-role RBAC (Admin, Supervisor, Operator, Auditor), and WebGL power flow HUD.

#### 02. Spectra — Vision-Based Automated Inspection Platform

`EDGE AI` · `COMPUTER VISION` · `INDUSTRIAL METROLOGY` · `SURFACE INSPECTION`

> **Continuous computer vision pipeline engineered for real-time surface defect classification and dimensional measurement on industrial components.**

- **Engineering Problem:** Manual visual quality inspection on high-throughput manufacturing lines (cylindrical rods, pipes, precision components) is inherently slow, subjective, and prone to human inspection fatigue.
- **Engineering Approach:** ESP32-CAM ingests low-latency video frames over Wi-Fi/HTTP into a multi-threaded Python backend where a fine-tuned YOLOv8 model detects surface flaws and OpenCV algorithms compute dimensional measurements in real time, serving live telemetry to an operator dashboard.

#### 03. ReckonBot V2X (GeoPace Edition) — GPS-Geofenced Autonomous Teleoperated Vehicle

`ROBOTICS` · `V2X TELEMATICS` · `DUAL-MCU` · `GEOFENCING`

> **Robotics platform uniting dual-microcontroller drive mechanics, live video streaming, polygon GPS geofencing, and browser-based remote teleoperation.**

- **Engineering Problem:** Single-microcontroller robotic vehicles suffer dangerous latency spikes and motor jitter when high-bandwidth video encoding saturates the MCU handling real-time actuation.
- **Engineering Approach:** Dual-MCU architecture isolates workloads: an ESP32 DevKit executes deterministic motor PWM and Haversine GPS geofencing calculations, while a dedicated ESP32-CAM processes MJPEG video compression and web proxying. Restricted zones trigger automated motor speed throttling and acoustic horn suppression.
- **Key Implementation:** Dual-MCU hardware partitioning, Haversine polygon geofencing algorithm, adaptive PWM motor throttle governor, state-driven buzzer safety suppression, UDP auto-discovery service for zero-config networking, and real-time React 19 teleoperation cockpit.
